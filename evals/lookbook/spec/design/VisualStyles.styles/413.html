Protocol · query

method 0941
  1. SELECT p.name AS project, count(*) AS open_overdue
  2. FROM tasks t
  3. JOIN projects p ON p.id = t.project_id
  4. WHERE t.status <> 'done'
  5. AND t.due_on < current_date
  6. GROUP BY p.name
  7. ORDER BY open_overdue DESC;
