Spacing, density and surface

Spacing
4px base on an 8px rhythm. 28px between cards, 16px between file tiles, 22px card padding.
Density
Roomy. Each file is its own raised tile with a round icon well.
Corners
24px cards, 20px tiles, 22px pill buttons, fields and toggles, round wells.
Borders
None. Edges come only from light and shade.
Shadows
Raised is 6px 6px 14px #1c1e23 with -6px -6px 14px #3a3e48. Small raised is half that. Pressed is the same pair inset, used for the selected file, the current nav item, search and fields.
Icons
18px line icons, blue when current. Chips pair a filled star, two people or an up arrow ring with the word.
Focus
3px solid blue outline, 4px offset, never a shadow alone.
