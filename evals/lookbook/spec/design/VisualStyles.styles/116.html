Style sheet

Style 116 · Manila folders

The dashboard is a desk file pulled from a steel drawer: manila folders with typed tab labels, rubber-stamped dates and statuses, and paper-clipped cards for the numbers.

Palette

  • Floor#e6e3dc page behind everything
  • Drawer steel#c8ccc6 header drawer front
  • Manila#ead39b main folder, current tab
  • Manila deep#dfc282 project folders, back tabs
  • Folder edge#cfae68 edges and stacked sheets, decorative
  • Label white#fbfaf4 typed labels, cards, memos
  • Ink#2a2015 text, primary button
  • Brown#59432a captions and field keys
  • Stamp red#a3201a overdue, Behind, current tab mark
  • Stamp blue#1d3c86 date stamp, At risk, this week, focus
  • Stamp green#2a5a22 On track stamp

Typed: "Courier New", Courier, "Nimbus Mono PS", monospace. Stamp: Impact, Haettenschweiler, "Arial Narrow Bold", sans-serif. Body: "Gill Sans", "Gill Sans MT", "Trebuchet MS", system-ui, sans-serif.

Surface rules

Spacing
8px unit. 48px between folder rows to leave room for tabs, 28–32px folder padding.
Density
Medium. One project per folder, facts as a short key and value list.
Corners
Folder tabs 8–10px on top, folders 4–6px except the corner under the tab, labels and buttons 2px, round date stamp.
Borders
1px folder edges, 3px stamp frames with an inner ring, dashed for At risk, 4px for Behind.
Shadows
Flat offset copies of the folder in deeper manila, like a stack, plus one soft drop under the main folder.
Icons
Inked stroke marks inside stamps: tick for On track, triangle for At risk, cross for Behind, clock for overdue. Steel paper clips as decoration.
Tone
Office filing words in typed caps, such as Desk file, Routing slip and Received.
Focus
3px dashed stamp blue outline offset 3px.
