System

Type stack
Segoe UI, Selawik, Helvetica Neue, Arial, Liberation Sans, sans-serif. Weights 400 and 600.
Layout
Blue masthead, then a white bar of icon tabs for the six areas. A 1280px shell with title row, overdue alert and a four-cell KPI band. Projects table at left with team tabs; chart and activity panels at right, each with its own tab strip.
Spacing
8px unit. 16px panel padding, 24px between panels, 10px table cells.
Density
Medium high. A real table with six columns, tight rows of 44px.
Corners
2px on everything. Avatars are round.
Borders
1px rule borders on every panel and row; the current tab carries a 3px blue underline.
Shadows
None. Panels sit flat on the grey shell.
Icons
1.6px line icons at 18px beside nav tabs and KPI labels. Status uses solid shapes with a white glyph.
Focus
A 2px blue outline with a 2px white gap, as box-shadow 0 0 0 2px white, 0 0 0 4px blue.
Tone
Neutral and precise. Short labels, column heads in caps, counts in tabs.
