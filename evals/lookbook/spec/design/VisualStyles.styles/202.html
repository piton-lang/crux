Spacing, density and surface

Spacing
8px unit. 24px page padding and section gaps, 32px between main blocks, 12 to 16px inside cells.
Density
Medium. A full width ruled table, values set in mono.
Corners
Square everywhere. Only avatars and the timeline dots are circles.
Borders
1px #111 on every component, shared edges collapsed into one rule. 1px #bdbdbd between rows. Blue 1px for the current or urgent thing, drawn as an inset second outline.
Shadows
None. No fills either; progress and this week bars use a 1px blue diagonal hatch.
Icons
Line icons at 1.6 to 1.8 stroke in currentColor. Status tags use a check circle, a triangle and a crossed square, Behind doubled in blue.
