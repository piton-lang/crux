Style 47 · Raw HTML

Idea: The page looks almost unstyled, like hand-written HTML from the late 1990s, with Times, blue underlined links, grey bevel buttons, rules and bordered tables.

Everything else

  • Spacing: browser defaults. 8px body margin, paragraph gaps, 4px cell padding, 2px cell spacing.
  • Density: dense and long. Everything flows top to bottom with no columns except the header table.
  • Corners: square, always.
  • Borders: outset 2px tables with inset 1px cells; 1px grooved horizontal rules between parts.
  • Shadows: none, only bevels made of white and grey edges.
  • Icons: none. Text symbols only: a check mark before Changes saved, a warning sign beside WARNING, arrows around the current section.
  • Tone: literal and a bit stiff: Logged in as, WARNING!, Table 1.
