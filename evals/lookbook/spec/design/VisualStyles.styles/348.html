Style 348 · BBS ANSI

A chat that behaves like a dial-up message board, drawn in sixteen-colour ANSI with shade-block banners, double-line boxes, hotkey menus and a message reader that counts MSG 1/5.

  • grey #aaaaaa body, offline, footer bar

≡ Spacing and shape

Spacing
Character grid. 10px between message frames, 20px between boxes.
Density
Busy and full. Every region boxed, a header bar on every message.
Corners
Square.
Borders
4px double cyan box rims with the label cut into the top edge, 1px cyan message frames.
Shadows
Only a hard 3px brown drop under the title text.
Icons
Block glyphs. ■ on-line, ▄ away, · off-line, ► thread, ◄ HERE, always with words.
Focus
A solid yellow block with black text.
Tone
Shouty sysop labels, such as 4 NEW, @1 FOR YOU, FILE ATTACHED and Enter text>.
